# paper/

Manuscript and publication-ready materials for:
*Counterfactual Explanations for Geometric Molecular Graph Neural Networks*

## Structure

```
paper/
├── drafts/       # Working drafts (versioned by date or section)
└── figures/      # Final, publication-ready figures (300 DPI PNG or PDF/SVG)
```

## Draft Naming

```
drafts/draft_{YYYY-MM-DD}.pdf   or   drafts/draft_{YYYY-MM-DD}.tex
```

## Figure Checklist (before submission)
- [ ] All figures are vector (PDF/SVG) or 300 DPI raster
- [ ] Font sizes readable at column width (~3.25 in)
- [ ] Color scheme is colorblind-friendly
- [ ] All figure captions are self-contained
- [ ] Figures match the exact experimental results in `results/`
