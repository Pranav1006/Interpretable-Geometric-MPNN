# src/

Core source code for IG-MPNN, organized by the four research pillars.

| Module | Pillar |
|---|---|
| `model/` | Geometric MPNN |
| `explanation/` | Explanation Module |
| `counterfactual/` | Counterfactual Generator |
| `evaluation/` | Evaluation Framework |
| `data/` | Data loading and featurization |
| `utils/` | Shared helpers |

Each module contains its own `README.md` describing its components and design decisions.
