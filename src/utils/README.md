# src/utils/ — Shared Utilities

## Purpose
Reusable helpers shared across all modules.

## Planned Components
- `logging.py`       — Centralized logger setup
- `chemistry.py`     — RDKit wrappers (SMILES ↔ graph, validity checks)
- `geometry.py`      — Distance, angle, torsion computation
- `visualization.py` — Molecule and graph rendering helpers
- `io.py`            — Saving/loading results, configs, and checkpoints
- `seed.py`          — Reproducibility (random seeds for torch, numpy, random)
