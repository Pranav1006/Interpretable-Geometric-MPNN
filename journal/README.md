# journal/

Research journal for IG-MPNN. Each entry is a dated Markdown file capturing
decisions, hypotheses, experimental observations, and open questions.

This is a living document — write here often. It will be invaluable when writing
the paper's methods, results, and discussion sections.

## Entry Convention

Filename: `YYYY-MM-DD_short-title.md`

## Entry Template

```markdown
# YYYY-MM-DD — Title

## What I Did
Brief summary of the session's work.

## Key Decisions
- Decision and rationale.

## Observations
- What worked, what didn't.

## Hypotheses
- New hypotheses raised by today's results.

## Open Questions
- [ ] Question to resolve in a future session.

## Next Steps
- [ ] Concrete next action.
```
